# Audio Directory for LOVE.EXE

Drop your custom romantic songs and audio files here!

## Supported Formats
- MP3 (`.mp3`)
- OGG (`.ogg`)
- WAV (`.wav`)

## Default Expected Filenames
- `our-song.mp3` -> Played as Track 2 in the audio player.
- `drive.mp3` -> Played as Track 3 in the audio player.

## Built-In Procedural Fallback
If no MP3 is found here, LOVE.EXE automatically uses its built-in Web Audio API romantic synth chords, so the site is never silent and never crashes!

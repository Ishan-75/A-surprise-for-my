# Images Directory for LOVE.EXE

Drop your personal photos here to show in the Memory Galaxy and Final Surprise!

## Suggested Usage:
1. Copy photos of you and Suganthi into this directory (e.g. `first-date.jpg`, `roadtrip.jpg`).
2. Update the `photoUrl` field in `src/data/memoryData.js`:
   ```javascript
   photoUrl: "/images/first-date.jpg"
   ```
3. If an image is omitted or missing, an artistic procedural starry card is displayed automatically!
